# Evidencias Proyecto — Fase 2

Esta carpeta reúne el trabajo técnico real del proyecto, separado en dos partes:

- **`Evidencias de documentación/`** — todo lo que el Instructivo pide como "elementos obligatorios independiente de la metodología" (arquitectura, modelo de datos, diagramas UML, requisitos no funcionales) más los artefactos propios de Scrum (Sprint Backlogs, retrospectivas).
- **`Evidencias de sistema/`** — el código funcionando: backend, app móvil y base de datos.
