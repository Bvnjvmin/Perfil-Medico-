# Fase 2 — Desarrollo del Proyecto APT

Estructura basada en el Instructivo CAPSTONE y en el ejemplo de repositorio que compartió el docente.

- **`Evidencias Grupales/`** — documentos oficiales de la fase (2.3, 2.4, 2.6, planillas de evaluación), que se agregan a medida que el docente los entrega.
- **`Evidencias Individuales/`** — Diario de Reflexión (2.1) y Formativa/Autoevaluación (2.2) de cada integrante.
- **`Evidencias Proyecto/`** — todo el trabajo técnico real: documentación de diseño y el sistema en desarrollo (código, base de datos).

Ver también la [Guía de Trabajo con Scrum — Fase 2](../Guia_Scrum_Fase2_PerfilMedico.docx) para cómo se organiza el trabajo sprint a sprint.
