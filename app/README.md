**Responsable:** Matías Pizarro
**Stack:** Flutter (Dart)

## Qué va aquí

Esta carpeta contendrá la aplicación móvil, siguiendo la estructura definida en el Plan de Trabajo (ver `/docs`):

```
app/
├── lib/
│   ├── screens/             # pantallas (login, perfil, rutinas, dashboard cuidador...)
│   ├── widgets/              # componentes reutilizables
│   └── services/              # consumo de la API (backend/)
├── assets/
└── pubspec.yaml
```

## Módulos planificados (Fase 2)

| Sprint | Módulo | Semanas |
|---|---|---|
| 1 | Registro/login y navegación inicial | 5-6 |
| 2 | Registro y confirmación de rutinas de cuidado | 7-8 |
| 3 | Panel de gestión de perfiles dependientes | 9-10 |
| 4 | Notificaciones push e interfaz simplificada (adulto mayor) | 11-12 |
| 5 | Indicadores de salud, botón de asistencia y consulta a IA | 13-15 |
